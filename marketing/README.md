## Campaign images

The final campaign uses two deliberately separate source layers:

1. `source/appshots/` contains the approved TabShow 2.0 captures. `source/appshots-2.1/` contains the new raw TabShow 2.1 capture set and a companion brief for every image. These pixels are never regenerated by imagegen.
2. `source/imagegen/editorial/` contains imagegen-created editorial problem scenes: tab overload, search, keyboard control, multiple windows, and sorting. They contain no fake UI or text.

`finalize_imagegen_assets.py` composites the exact appshots into those scenes, adds deterministic typography, and exports sharp RGB PNGs at the required dimensions. Run it with the bundled workspace Python runtime:

```bash
/Users/spetreikis/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 marketing/finalize_imagegen_assets.py
```
