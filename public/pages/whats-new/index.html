What’s fixed

Less ambiguity. Less clutter.

◉

Stable open-tab totalsFiltering search results no longer makes the open-tab or window count appear to shrink.

◎

Theme-aware palettesActive and preview colors stay distinguishable in both light and dark appearance modes.

↗

Cleaner window listsThe redundant current-window banner is gone, while tabs in other windows still have explicit switch markers.

✓

More predictable controlsSearch focus, Arrow key selection, Enter, Escape, and configurable preview delays have broader regression coverage.
