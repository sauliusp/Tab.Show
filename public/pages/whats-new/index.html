TabShow 2.2 adds an optional way to support the project and makes keyboard navigation more predictable when you follow a link.

Every feature is free. Supporting the project is entirely optional.

01

An optional thank-you

A coffee for the maker.

There is now a quiet Support TabShow link at the bottom of the panel, and a Buy me a coffee button in Settings. If TabShow makes your day easier, you can leave a small tip.

No paid features, reminders, or extra permissions.

02

A keyboard fix

Links behave like links.

Pressing Enter on a focused link opens that link without switching to a tab in the list. Escape still returns to your original tab and closes the panel, even when a support link has focus.

Choose a shortcut you’ll actually use.

Suggested defaults are Command + Shift + X on Mac and Ctrl + Shift + X on Windows or Linux. Chrome may leave the shortcut unassigned if it conflicts with another extension.
