# TabShow 2.3

All windows now makes its scope clear: the Chrome profile you are using. Windows in other profiles, such as Work and Personal, stay separate. Open TabShow in that profile to see its tabs.

A new narrated demo shows the essentials in about 30 seconds: hover to preview the full page, move away to return, and click to stay. Search and keyboard navigation follow, with room to see each action.

Every feature remains free. No new permissions or tracking.

Release package and publication gates: `docs/releases/2.3.0/README.md`.
