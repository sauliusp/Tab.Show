# Traditional Chinese listing copy : TabShow 2.4

Locale: `zh_TW`. Candidate copy for the 2.4 release; no publication or approval is implied by this file. Use with the matching localized extension and gallery, once reviewed.

## Store title

TabShow：即時分頁預覽

## Summary

切換前先預覽 Chrome 分頁的即時畫面。搜尋分頁，找到需要的網頁，不必反覆切換尋找。

## Detailed description

分頁開太多，忘了哪個才是要找的？TabShow 把分頁放進可搜尋的 Chrome 側邊欄。將滑鼠停在清單中的分頁上，就能看到完整的即時網頁；確認是需要的內容後，再點選切換。

先預覽，再決定
• 將滑鼠停在目前視窗中的分頁上，預覽網頁的即時畫面。
• 將滑鼠移出側邊欄，就會回到原來的分頁。
• 點選分頁或按 Enter，確認切換。

用搜尋和鍵盤找到分頁
• 搜尋標題、網址或網域。
• 用 ↑ 和 ↓ 選取結果，按 Enter 開啟。
• 按 Esc 取消預覽、返回原來的分頁並關閉側邊欄。
• 可依目前順序、最近使用、最近新增（大約）、網域或分頁群組排序。排序方式會保留。

查看同一個 Chrome 個人資料中的視窗
• 在「目前視窗」和「所有視窗」之間切換。
• 其他視窗的分頁依視窗分區顯示，點選即可切換。
• 滑鼠經過其他視窗的分頁時不會預覽或搶走焦點。
• 其他 Chrome 個人資料的視窗不會顯示在清單中。

依照習慣調整
• 在設定中開啟「選擇分頁後保持側邊欄開啟」，點選分頁後清單就會留在網頁旁邊。此選項預設關閉。
• 可調整預覽延遲，或關閉「滑鼠停留時預覽分頁」，只用點選或鍵盤切換。
• 支援淺色、深色與系統外觀，以及多種配色。系統外觀跟隨淺色或深色偏好，不會套用自訂 Chrome 主題的顏色。
• 開啟側邊欄時，目前分頁會自動出現在可見位置。

不改變你現有的分頁
TabShow 顯示現有分頁，保留 Chrome 分頁群組，也能看見固定、播放音訊、靜音、休眠和重複分頁的標示。本機計算的「分頁混亂分數」可供參考，不會自動關閉或重整分頁。

免費與隱私
所有功能免費使用，不必建立帳號。分頁資料留在瀏覽器中。TabShow 不使用分析追蹤，也不會將分頁資料上傳到伺服器。「支持 TabShow」連結完全自願。

開啟方式
點選工具列中的 TabShow 圖示，或設定鍵盤快捷鍵。建議預設快捷鍵為 Mac 的 Command + Shift + X，以及 Windows／Linux 的 Ctrl + Shift + X。如果按鍵已被其他擴充功能使用，可到 Chrome 的擴充功能快捷鍵設定自行指派。

Chrome 的固定圖示只會將 TabShow 放到工具列上。若想在選擇分頁後保留側邊欄，請使用 TabShow 設定中的「選擇分頁後保持側邊欄開啟」。

TabShow 支援英文、德文、簡體中文和繁體中文，並依照 Chrome 的介面語言自動選擇。側邊欄、設定、歡迎頁與擴充功能內的更新內容皆已翻譯；網站及連結的外部說明頁面目前仍為英文。

## Gallery copy

1. **切換前，先看看網頁**
   將滑鼠停在分頁上即可預覽即時畫面。移出側邊欄，回到原來的位置。
2. **輸入文字，找到分頁**
   搜尋標題、網址或網域。
3. **用鍵盤就能切換**
   ↑↓ 選取，Enter 開啟，Esc 返回並關閉。
4. **同一個個人資料中的所有視窗**
   其他視窗的分頁需要點選才會切換，滑鼠經過不會搶走焦點。
5. **讓側邊欄留在旁邊**
   在設定中開啟「選擇分頁後保持側邊欄開啟」。預設仍會在選擇後關閉。
