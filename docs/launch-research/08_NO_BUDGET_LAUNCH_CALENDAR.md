# TabShow No-Budget Launch Calendar

## Purpose

Create a practical organic distribution calendar for TabShow without paid ads.

## Precondition

Before launch push:

- Chrome Web Store positioning updated.
- Website hero updated.
- 15-second demo ready.
- At least one clear feature improvement shipped, ideally search or keyboard navigation.
- Tab Chaos Score planned or shipped.

## Week 1: Positioning and Proof

Actions:

- Update Chrome Web Store title/description/screenshots.
- Update homepage headline to "Find the right Chrome tab without switching away."
- Create short demo GIF/video.
- Publish `/chrome-tab-preview-extension`.

Post:

- X/LinkedIn build-in-public post with demo.

Goal:

- Make the product immediately understandable.

## Week 2: Community Feedback

Actions:

- Post to r/chrome_extensions with builder feedback framing.
- Reply to comments.
- Capture objections and feature requests.
- Add FAQ entries based on real comments.

Post:

- Reddit post: "I built a tiny Chrome extension for people with too many tabs."

Goal:

- Get authentic feedback and early users without looking promotional.

## Week 3: Competitor Intent

Actions:

- Publish `/onetab-alternative`.
- Publish `/workona-alternative`.
- Publish `/tab-manager-plus-alternative`.
- Add comparison snippets to homepage or FAQ.

Post:

- X/LinkedIn comparison thread:
  - OneTab saves memory.
  - Workona organizes projects.
  - Tab Manager Plus manages tabs.
  - TabShow previews live tabs without switching.

Goal:

- Start compounding SEO and clarify positioning.

## Week 4: Shareable Asset

Actions:

- Ship or prototype Tab Chaos Score.
- Create redacted share card.
- Publish post around tab chaos stats.

Post:

- "How many Chrome tabs is too many? I built a local Tab Chaos Score."

Goal:

- Create a reason for users to share that is about them, not only about TabShow.

## Week 5: Product Hunt / Show HN Candidate

Actions:

- Polish launch assets.
- Collect 5-10 real user quotes/reviews if available.
- Prepare launch page.

Launch angle:

> Preview Chrome tabs without switching away.

Goal:

- Use Product Hunt/HN as an amplification moment after the product and narrative are clearer.

## Weekly Maintenance After Launch

Every week:

- One small improvement.
- One demo/changelog post.
- One community scan.
- One SEO improvement.
- One review ask optimization.

## Success Metrics

Track:

- Installs.
- Active users.
- Review count.
- Chrome Web Store rating.
- Website -> Chrome Web Store clicks.
- Best-performing post.
- Best-performing SEO page.
- Most repeated objection.

## Guardrail

Do not burn communities with repetitive promotion. Distribution should feel like:

- A builder asking for feedback.
- A useful comparison.
- A funny/relatable tab-chaos moment.
- A real product improvement.

Not:

- Link spam.
- Generic launch copy.
- Fake virality.
