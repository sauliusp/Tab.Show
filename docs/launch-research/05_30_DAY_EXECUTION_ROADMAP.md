# TabShow 30-Day Improvements and GTM Roadmap

## Goal

Make TabShow easier to understand, easier to adopt, and easier to share without bloating the product.

Core theme:

> Find the tab without switching.

## Week 1: Product Activation

Ship:

- Search by title and URL.
- Keyboard navigation:
  - Type to search.
  - Arrow keys to move.
  - Enter to switch.
  - Esc to return/snap back.
- First-run aha onboarding:
  - "Hover a tab to preview it."
  - "Move away to snap back."
  - "Click to switch."

Update:

- Chrome Web Store screenshots.
- Homepage hero.
- Short description.

Success metric:

- More users reach first successful preview.
- More users reopen the side panel after first install.

## Week 2: Power User Credibility

Ship:

- Multi-window grouping.
- Recently used sorting.
- By-domain grouping/sorting.
- Tab indicators:
  - Audio.
  - Pinned.
  - Duplicate.
  - Tab group.

Update:

- Add "Built for 100+ tabs" proof section.
- Add "No account, no backend, no host permissions" trust section.

Success metric:

- More repeat usage by heavy tab users.
- More feature-specific review mentions.

## Week 3: Viral Asset

Ship:

- Local Tab Chaos Score:
  - Tab count.
  - Window count.
  - Duplicate count.
  - Top domains.
  - Oldest tab if available.
- Share card generator:
  - Redacted by default.
  - Optional domain visibility.
  - tab.show watermark.
  - Install URL/QR.

Create:

- 15-second demo video.
- 30-second demo video.
- GIF for Chrome Web Store/homepage.
- Three social posts.

Success metric:

- Shares/clicks from share card.
- Higher install conversion from demo assets.

## Week 4: Relaunch

Publish:

- TabShow vs OneTab.
- TabShow vs Workona.
- TabShow vs Tab Manager Plus.
- Best Chrome tab preview extension.
- How to find the right Chrome tab when you have 100 open.

Launch:

- Product Hunt.
- Reddit r/chrome_extensions.
- Reddit r/productivity.
- X/LinkedIn build-in-public thread.
- Optional Show HN if privacy/implementation story is strong.

Success metric:

- Chrome Web Store installs.
- Review count and average rating.
- Homepage-to-store click-through.
- Store listing conversion.

## Backlog After 30 Days

Consider:

- Pin/unpin from panel.
- Mute/unmute from panel.
- Close duplicate tabs.
- Saved per-window/tab-group preferences.
- Optional import/export of TabShow settings.

Avoid for now:

- Cloud sync.
- Team workspaces.
- Notes/tasks.
- Full bookmark manager.
- Full session manager.

## Operating Principle

Every new feature must support one of these jobs:

1. Recognize the right tab faster.
2. Return to the original tab safely.
3. Reduce context switching.
4. Help users share their tab chaos without exposing private data.

If it does not support one of those jobs, it probably belongs in another product.
