# TabShow Messaging and SEO

## Positioning

Primary positioning:

> TabShow lets you preview any Chrome tab by hovering, so you can find the right page without losing your place.

Short version:

> Hover. Preview. Focus.

Category phrase:

> Visual tab pointer for Chrome.

Avoid leading with:

- Best free Chrome tab manager.
- Tab organizer.
- Workspace manager.
- Productivity extension.

Those phrases are either too broad or already owned by stronger categories.

## Website SEO Page Strategy

The marketing website, likely tab.show, should become the SEO and distribution base. The Chrome Web Store remains the conversion point.

Recommended first pages:

1. `/chrome-tab-preview-extension`
   - Goal: own the exact product behavior.
   - Angle: "Preview live Chrome tabs without switching away."

2. `/onetab-alternative`
   - Goal: intercept memory/session tool searches.
   - Honest comparison: OneTab closes tabs to save memory. TabShow keeps tabs live and helps you recognize the right one.

3. `/workona-alternative`
   - Goal: intercept workspace-tool searches.
   - Honest comparison: Workona is for project workspaces and sync. TabShow is lightweight live preview with no account.

4. `/tab-manager-plus-alternative`
   - Goal: intercept utility tab manager searches.
   - Honest comparison: Tab Manager Plus is a management dashboard. TabShow is a faster recognition loop.

5. `/find-lost-chrome-tab`
   - Goal: capture pain-led search.
   - Angle: "When Chrome tab titles collapse to favicons, use live preview instead of guessing."

Page rule:

Every SEO page should point to a specific job-to-be-done, include one short demo/GIF, explain who should use the competitor instead, and end with a Chrome Web Store CTA.

Do not create thin keyword pages. Make them useful enough to share in Reddit comments without looking spammy.

## Chrome Web Store ASO

The Chrome Web Store listing should be treated as a second search surface.

Priority changes:

- Title: include "live tab preview" or "hover to preview Chrome tabs."
- Short description: lead with "preview without switching."
- First screenshot: show too many tabs and the side panel.
- Second screenshot: show hover preview.
- Third screenshot: show snap back / click to switch.
- Fourth screenshot: privacy proof: no account, no backend, no host permissions.
- Long description: mention Chrome tab preview, side panel tabs, tab groups, many tabs, local/private.

Review velocity:

Ask only after usage. Reviews from real users matter more than generic early asks.

## Brand Voice

TabShow should sound like a small sharp tool, not a bloated SaaS product.

Use:

- Plain language.
- Real tab pain.
- Privacy-first confidence.
- Founder/builder honesty.
- Slight humor around tab chaos.

Avoid:

- Generic productivity claims.
- Overpromising focus or ADHD outcomes.
- "AI-powered" unless it becomes true and useful.
- Enterprise-style copy.
